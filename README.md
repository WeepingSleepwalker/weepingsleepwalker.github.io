# Francis Chung Website

This project is a no-build static website prepared for free hosting on GitHub Pages.

## Files

- `index.html` contains the homepage.
- `work.html` contains the portfolio grid and stand-in work slots.
- `about.html` contains the bio and artist statement.
- `contact.html` contains direct contact details.
- `styles.css` contains the shared design system and responsive layout.
- `script.js` contains the mobile menu, reveal animations, and canvas interactions.

## Before Publishing

1. Replace the six stand-in work cards in `work.html` with final artwork titles, years, materials, dimensions, and images.
2. Add the correct Instagram handle and link in `contact.html`.
3. If you have final photography, place the image files in an `assets/` folder and update the work cards to use `<img>` tags instead of the current gradient placeholders.

## Publish On GitHub Pages

1. Create a GitHub repository and upload these files to the root of the default branch.
2. In GitHub, open `Settings` -> `Pages`.
3. Under `Build and deployment`, choose `Deploy from a branch`.
4. Select your main branch and the `/ (root)` folder, then save.
5. Wait for GitHub to publish the site and use the generated `github.io` URL for the contest submission.

## Local Preview

If you want a one-command local preview, install Node.js first.

From this folder, run:

```bash
npm run dev
```

Then open `http://127.0.0.1:8000`.

If you do not want to use npm, the direct fallback is:

```bash
python3 -m http.server 8000
```
My sculptures build pressure into form. I am drawn to objects that feel unstable but deliberate — bodies under load, forces in negotiation, things that might tip or collapse but haven't yet. The work emerges through making rather than illustration: structural relationships, psychological weight, and the charge that accumulates when familiar forms are pushed toward the unfamiliar.
These pieces explore states of being in the body — uprightness as aspiration and precarity, gravity as surrender and containment, presence as something that can be felt even in absence. The forms are ceramic but think in terms of architecture: weight, compression, balance, the moment before failure.

Uprightness
Ceramic with gold and black glaze
"Two forces in negotiation — the luminous and the grounded, neither fully stable without the other. The piece asks whether uprightness is something you achieve or something you perform."

I Was Never There
Ceramic with teal, green, and chartreuse glaze
"A body that occupies space without claiming it — present enough to stand, absent enough to disappear. The title came before the form, and the form kept agreeing with it."

Gravity
Ceramic with matte black glaze
"Collapse as posture. The satellites orbiting the central mass aren't falling away — they're holding it together, or being held. I'm still not sure which.

SuperStressed
Ceramic with metallic glaze
"The mask doesn't hide the face — it is the face. A figure at the edge of composure, holding it together through clenched teeth and sheer force of will."

Ceramic Sculpture — Directly Relevant
Peter Voulkos — broke ceramic sculpture free from craft into fine art. Abstract Expressionist influence. This connection to your work is solid.
Ken Price — biomorphic glazed ceramic objects with serious chromatic sophistication. The most direct formal relative to your creatures and egg.
Rudy Autio — expressive ceramic figuration. Relevant to your busts.

Sculpture — Broader Formal Connections
Brâncuși — pure form, the ovoid as ur-form. Your egg is genuinely in this conversation.
Giacometti — psychological weight between figures. Relevant to Falling Apart.
Louise Bourgeois — body, psychological intensity, categorical refusal. Solid connection.
Martin Puryear — craft and fine art boundary. Legitimate comparison.

Contemporary
Theaster Gates — ceramics, Black cultural memory, faith. Real connection though I overstated the direct parallel earlier.
Simone Leigh — ceramic figuration, African traditions. Same caveat.
Woody De Othello — contemporary ceramic sculpture. Worth looking at seriously.
